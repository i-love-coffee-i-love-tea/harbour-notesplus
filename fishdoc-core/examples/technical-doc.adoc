== Overview

This document describes the architecture of the FishDoc application.

== Architecture

FishDoc uses a 3-crate workspace:

1. `fishdoc-core` — Pure Rust core library
2. `fishdoc-sailfish` — Sailfish OS GUI
3. `vendor/sailors` — SailfishApp FFI

== Data Model

=== Storage

* *Files*: `~/.local/share/harbour-fishdoc/notes/*.adoc`
* *Database*: `~/.local/share/harbour-fishdoc/fishdoc.db`

=== SQLite Schema

[source,sql]
----
CREATE TABLE pages (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    filename TEXT NOT NULL UNIQUE,
    title TEXT NOT NULL,
    is_journal INTEGER NOT NULL DEFAULT 0,
    created_at TEXT NOT NULL,
    updated_at TEXT NOT NULL,
    block_count INTEGER NOT NULL DEFAULT 0
);
----

== API Reference

=== Block Types

[cols="1,2"]
|===
| Type | Description

| Heading
| Level 1-6 headings

| Paragraph
| Multi-line text blocks

| CodeBlock
| Delimited code blocks

| Table
| AsciiDoc tables
|===
