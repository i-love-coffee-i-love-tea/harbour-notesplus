== Overview

This document describes the architecture of the Notes Plus application.

== Architecture

Notes Plus uses a 3-crate workspace:

1. `notesplus-core` — Pure Rust core library
2. `notesplus-sailfish` — Sailfish OS GUI
3. `vendor/sailors` — SailfishApp FFI

[NOTE]
====
The core library has no Qt or Sailfish dependencies and can be tested independently with `cargo test -p notesplus-core`.
====

== Data Model

=== Storage

* *Files*: `~/.local/share/harbour-notesplus/notes/*.adoc`
* *Database*: `~/.local/share/harbour-notesplus/notesplus.db`

=== SQLite Schema

[source,sql]
----
CREATE TABLE pages (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    filename TEXT NOT NULL UNIQUE,
    title TEXT NOT NULL,
    is_journal INTEGER NOT NULL DEFAULT 0,
    created_at TEXT NOT NULL,
    updated_at TEXT NOT NULL,
    block_count INTEGER NOT NULL DEFAULT 0
);
----

== API Reference

=== Block Types

[cols="1,2"]
|===
| Type | Description

| Paragraph

| CodeBlock

|===
