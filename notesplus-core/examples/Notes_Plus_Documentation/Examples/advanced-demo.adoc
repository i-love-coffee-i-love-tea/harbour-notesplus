=== Project Structure

Notes Plus uses a multi-crate Cargo workspace:

1. `notesplus-core`
  * Parser (AsciiDoc to blocks)
  * Inline formatting (bold, italic, code, links)
  * SQLite storage with FTS5 search
  * Page CRUD operations
2. `notesplus-sailfish`
  * QML/Silica user interface
  * Rust-to-QML bridge via `qmetaobject`
  * Async page loading with poll timer
3. `vendor/sailors`
  * SailfishApp FFI bootstrap
  * Application lifecycle management

=== Build Steps

1. Install the Sailfish SDK
2. Clone the repository
3. Configure the build target:
  a. Open `build-sailfish.sh`
  b. Set `TARGET` to your SDK version
  c. Set `SAILFISH_WORKSPACE` path
4. Run `bash build-sailfish.sh`
5. Deploy the RPM:
  * `scp rpms/*.rpm user@phone:/tmp/`
  * `devel-su rpm -Uvh /tmp/harbour-notesplus-*.rpm`

=== Rust Parser

The inline parser handles nested formatting:

[source,rust]
----
fn parse_inline(text: &str) -> Vec<InlineSpan> {
    let mut spans = Vec::new();
    let mut pos = 0;
    while pos < text.len() {
        if let Some((span, consumed)) = try_match(&text[pos..]) {
            spans.push(span);
            pos += consumed;
        } else {
            pos += 1;
        }
    }
    spans
}
----

=== QML Rendering

Inline spans are rendered as RichText HTML:

[source,javascript]
----
function renderSpan(span) {
    switch (span.type) {
        case "bold": return "<b>" + renderSpans(span.spans) + "</b>"
        case "italic": return "<i>" + renderSpans(span.spans) + "</i>"
        case "code": return "<code>" + escapeHtml(span.value) + "</code>"
        case "xref": return "<a href='xref:" + span.target + "'>" + span.display + "</a>"
    }
}
----

== Important Notes

[NOTE]
====
The `qmetaobject` crate uses unsafe interior mutability. Never perform file I/O directly inside a `qt_method!` — always use a background thread with `Arc<Mutex<Option<Result>>>`.
====

[TIP]
====
Use `cargo test -p notesplus-core` to run all parser and storage tests without needing the Sailfish SDK.
====

[WARNING]
====
Always convert `Cargo.lock` from v4 to v3 before building with the Sailfish SDK. Rust 1.75 cannot parse lockfile v4.
====
